## How to loop

1. Read PROGRESS.md. Pick the first step below that is neither ticked nor blocked.
2. Do the step fully. Run its verification. Do not skip verification.
3. Commit on a branch named for the step. One PR per step group (see "Shipping").
4. Tick the step here and append a dated log line to PROGRESS.md: what was done,
   what was verified and how, what is next.
5. If blocked, write the blocker under Blocked in PROGRESS.md and move on.
6. Stop when every step is ticked or blocked.

## Decisions (final for this session)

D1 to D5 and D7 in `docs/CODEX-PLAN.md` stand. In particular: one signal per
source, no charts, no second figure, no rank copied from any source, no guessed
value, date, slug or URL.

D6 is REVERSED. UK Food Hygiene (https://ukfoodhygiene.co.uk) is public, crawlable
and carries 364 council pages. It becomes the fifth source. Record the reversal in
CODEX-PLAN.md with today's date and the reason, do not delete the original line.

D8. Estate house style applies: no em dashes or en dashes anywhere (prose, code
comments, JSON, alt text), no " - " pseudo-dash, British English, `n/a` as the null
cell, declarative voice, no political framing, titles use a pipe. Add a test that
greps `src/` and `scripts/` for the two dash characters; the one live offender is
`og:image:alt` in `src/layouts/BaseLayout.astro`.

D9. Shipping: push branches and open PRs. Do not merge to main. A push to main
deploys to production through `.github/workflows/deploy.yml`, and the merge is
Tom's call. Never touch DNS, Search Console, or any sister repo's main branch.

D10. Every place page stays indexable. After step 3 every one of the 361 records
has at least two sources (Asylum Stats and UK Food Hygiene both cover all 361), so
the playbook's noindex rule for thin pages does not fire. Do not add noindex.

## Facts verified 27 September 2026

- Live site: GitHub Pages, custom domain, 1,029 pages (361 places, 650
  constituencies, 12 regions, 6 static). Search Console reported 1,029 discovered
  on 10 September. A `site:ukplaces.co.uk` search returns only the home page.
- Every place has a templated title `<Name> | UK Places` and the description
  `<Name> geography record: local authority code, geography and source coverage.`
  The sitemap has no lastmod. JSON-LD has no dateModified, no containedInPlace and
  the registry `wikidata` field is null on all 361 records.
- Coverage today: ukelections 143 places, ukdemographics 318, aidoge 294,
  asylumstats 361. 43 places have a single source. Every Scottish and Northern
  Irish page is a GSS code plus one asylum figure, and prints "Scotland · Scotland"
  because region equals country.
- 164 places print "Parent county GSS code E10000017" style raw codes with no
  county name and no link. The 21 county councils have no page.
- A place page links to no region page, no county and no sibling place.
- All four sister sites link "Place record on UK Places" from their Burnley page.
- UK Food Hygiene join: `/Users/tompickup/ukfoodhygiene/etl/la_map.csv` (committed)
  maps FSA authority code to GSS code and `council_slug`. All 361 UK Places GSS codes
  match a council in `ukfoodhygiene/site/src/data/councils.json`; the two extras
  (Hull and Goole Port, River Tees) are port health authorities and are ignored.
  `councils.json` and `meta.json` are gitignored ETL output and on this Mac read
  20 September while the live site says 27 September; vps-main is canonical.
  Council page URL pattern: `https://ukfoodhygiene.co.uk/councils/<council_slug>/`.
  Accent: the site's theme-color is `#1f5c4a`.
- The food hygiene site's `site/src/components/SisterLinks.astro` links UK Elections
  at `/councils/<slug>/`, which 404s. The live route is `/seats/<slug>/`. It does not
  link UK Places at all.
- `www.ukplaces.co.uk` resolves to a non-GitHub nginx host (46.30.211.38) that 404s
  on HTTPS. Tom only; see the Tom list at the end.
- No analytics of any kind on the site.
- The home page source cards link to `/sources/`, not the source site, and the
  UK Demographics card says "police-recorded crime" while the manifest topic is
  population, crime and local context.
- 77 constituencies have no PCON code and no UK Demographics link (Scotland, Wales,
  Northern Ireland); region names render from snake_case on constituency pages.
- Fonts are self-hosted but not preloaded.
- AI DOGE's `data/shared/council_crosswalk.json` (975 bodies, `ons_code`) holds the
  names of the 21 county councils, source-confirmed. Use it for step 5, never a
  hand-typed list.
- Wikidata property P836 is the GSS code. A SPARQL lookup on P836 gives the QID for
  a local authority without guessing.

## Never

- Never estimate, apportion, carry forward or default a figure. A missing value is
  a blank signal.
- Never copy a rank, league position or comparison from any source.
- Never derive a sister-site slug from a name; only the registry mapping.
- Never add a second figure from the same source to a place page.
- Never push to main, change DNS, touch Search Console, or merge a PR.
- Never name a private individual. The food hygiene site lists business names;
  UK Places takes only the council-level figure.
